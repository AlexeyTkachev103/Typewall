# Quote Wallpaper Generator

Веб-приложение для создания красивых изображений с текстом (обои, цитаты, мотиваторы) на базе Flask.

## Возможности

### 🎨 Фон изображения
- **Сплошной цвет** - выбор любого цвета через палитру
- **Градиенты**:
  - Линейный (горизонтальный, вертикальный, диагональный TL-BR, диагональный TR-BL)
  - Радиальный
  - Два цвета для создания градиента

### 📐 Разрешения
- **Предустановленные**:
  - 800 × 600
  - 1024 × 768
  - 1920 × 1080 (Full HD)
  - 2560 × 1440 (2K)
  - 3840 × 2160 (4K)
- **Кастомное разрешение** - любые значения ширины и высоты

### ✍️ Текстовые блоки
- **Множественные блоки** - добавляйте неограниченное количество текстовых элементов
- **Многострочный текст** - поддержка переносов строк
- **10 шрифтов**:
  - Arial
  - Times New Roman
  - Courier
  - Georgia
  - Verdana
  - **Fira Code (Nerd Font)**
  - **JetBrains Mono (Nerd Font)**
  - **Hack (Nerd Font)**
  - **Roboto Mono (Nerd Font)**
  - **Source Code Pro (Nerd Font)**

### 🎯 Форматирование текста
- **Размер шрифта** - от 12px до 200px
- **Цвет текста** - любой цвет через палитру
- **Стили**:
  - Жирный (Bold)
  - Курсив (Italic)
  - Подчеркнутый (Underline)

### 📍 Позиционирование
9 предустановленных позиций для каждого текстового блока:
```
↖  ↑  ↗
←  ⊙  →
↙  ↓  ↘
```

### 👁️ Предпросмотр
- **Live preview** - обновление в реальном времени при изменении параметров
- Debounce 300ms для оптимизации
- Масштабирование под размер контейнера

### 💾 Экспорт
- **PNG** - без потери качества
- **JPEG** - высокое качество (95%)
- Скачивание напрямую в браузер

## Установка и запуск

### Требования
- Python 3.8+
- pip

### Быстрый старт

1. **Клонируйте репозиторий или перейдите в директорию проекта:**
```bash
cd quote-wallpaper
```

2. **Создайте виртуальное окружение:**
```bash
python -m venv venv
```

3. **Активируйте виртуальное окружение:**

Linux/macOS:
```bash
source venv/bin/activate
```

Windows:
```bash
venv\Scripts\activate
```

4. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

5. **Запустите приложение:**
```bash
python app.py
```

6. **Откройте в браузере:**
```
http://127.0.0.1:5000
```

## Использование

### 1. Настройка фона
- Выберите тип фона (сплошной цвет или градиент)
- Для сплошного цвета выберите цвет через палитру
- Для градиента:
  - Выберите два цвета
  - Выберите тип (линейный/радиальный)
  - Для линейного выберите направление

### 2. Выбор разрешения
- Выберите предустановленное разрешение из списка
- Или выберите "Custom" и укажите свои значения

### 3. Добавление текста
- Нажмите "+ Add Text Block" для создания текстового блока
- В каждом блоке:
  - Введите текст (поддерживается многострочный)
  - Выберите шрифт
  - Настройте размер (используйте slider)
  - Выберите цвет текста
  - Примените стили (жирный, курсив, подчеркнутый)
  - Выберите позицию на изображении

### 4. Управление блоками
- Для удаления блока нажмите "×" в правом верхнем углу блока
- Можно создавать неограниченное количество блоков
- Все блоки независимы друг от друга

### 5. Предпросмотр
- Изображение обновляется автоматически при изменении параметров
- Предпросмотр масштабируется для удобного просмотра

### 6. Экспорт
- Выберите формат (PNG или JPEG)
- Нажмите "Download Wallpaper"
- Файл сохранится в папку загрузок браузера

## Технологии

### Backend
- **Flask** 3.0.0 - веб-фреймворк
- **Pillow** 11.0.0 - обработка изображений

### Frontend
- **Vanilla JavaScript** - без зависимостей
- **CSS Grid/Flexbox** - адаптивная верстка
- **Fetch API** - асинхронные запросы

### Шрифты
- **DejaVu Fonts** - стандартные шрифты с поддержкой кириллицы
- **Nerd Fonts** - моноширинные шрифты с иконками для разработчиков

## API

### POST /preview
Генерирует предпросмотр изображения (base64)

**Request:**
```json
{
  "bg_type": "gradient",
  "gradient_color1": "#667eea",
  "gradient_color2": "#764ba2",
  "gradient_type": "linear",
  "gradient_direction": "horizontal",
  "width": 1920,
  "height": 1080,
  "text_blocks": [
    {
      "text": "Hello World",
      "font_family": "FiraCode",
      "font_size": 48,
      "text_color": "#ffffff",
      "bold": true,
      "italic": false,
      "underline": false,
      "position": "middle-center"
    }
  ]
}
```

**Response:**
```json
{
  "image": "data:image/png;base64,iVBORw0KGg..."
}
```

### POST /download
Генерирует и скачивает финальное изображение

**Request:** Те же параметры + `format` (png/jpeg)

**Response:** Файл изображения

## Примеры использования

### Создание мотивационной цитаты
1. Установите градиент (синий → фиолетовый, вертикальный)
2. Разрешение: 1920×1080
3. Добавьте текстовый блок:
   - Текст: "Твой текст здесь"
   - Шрифт: JetBrains Mono
   - Размер: 72px
   - Цвет: белый
   - Позиция: центр
   - Стиль: жирный

### Создание обоев для рабочего стола
1. Сплошной фон: темно-синий (#2c3e50)
2. Разрешение: 2560×1440
3. Добавьте несколько блоков с кодом/цитатами
4. Используйте Nerd Font для иконок
5. Экспортируйте в PNG

### Создание превью для YouTube
1. Градиент радиальный
2. Разрешение: 1920×1080
3. Крупный текст сверху (заголовок)
4. Мелкий текст снизу (подзаголовок)
5. Экспорт в JPEG

## Советы

- **Nerd Fonts** содержат тысячи иконок - просто скопируйте символ в текстовое поле
- Для читаемости используйте контрастные цвета текста и фона
- Жирный шрифт лучше виден на маленьких превью
- Для социальных сетей используйте стандартные разрешения
- PNG для прозрачности и качества, JPEG для меньшего размера

## Разработка

### Добавление новых шрифтов
1. Скачайте .ttf файл шрифта
2. Поместите в `static/fonts/`
3. Добавьте в `app.py` в словарь `font_variants`
4. Добавьте опцию в HTML (`templates/index.html`)

### Добавление новых позиций
1. Добавьте позицию в `POSITIONS` в `app.py` (координаты 0.0-1.0)
2. Добавьте кнопку в HTML с `data-position`
3. CSS стили применятся автоматически
